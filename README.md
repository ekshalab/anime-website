# Exploring the World of Anime

A multi-page website exploring the history, evolution, and cultural impact of anime, from its origins in early 20th-century Japan to its role in global pop culture today.

## About

This project was built to document anime's journey: how it started, the studios and creators who shaped it, and how it's consumed and represented in the world today. It's a multi-page site with consistent navigation and a custom error page.

## Pages

- **Home** (`home.html`) – What anime is, why it matters, and a set of quick facts (e.g. Spirited Away winning the Academy Award for Best Animated Feature, the longest-running anime series exceeding 7,500 episodes)
- **History** (`one.html`) – A timeline from anime's 1917 origins through Osamu Tezuka and Astro Boy, its global expansion in the 1980s-90s (Dragon Ball, Sailor Moon, Naruto, Pokémon), and the studios that shaped it (Studio Ghibli, Toei Animation, Madhouse)
- **Anime Today** (`two.html`) – Modern production styles, major genres (Shonen, Shojo, Seinen, Fantasy/Isekai), and anime's reach through streaming platforms, conventions, and fashion
- **404 Page** (`404.html`) – A custom error page ("This page wandered off like Totoro") that redirects users back to the homepage instead of leaving them stuck

## Built With

- HTML5
- CSS

## Features

- Consistent multi-page navigation across the whole site
- Custom-designed 404 error page with a clear path back to the homepage
- Content organized into distinct, readable sections per page
